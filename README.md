# Classic Family Photography

Premium Next.js + TypeScript + Prisma/PostgreSQL photography studio website.

Run:

```bash
npm install
npx prisma generate
npx prisma migrate dev
npm run seed
npm run dev
```

Public site: http://localhost:3000
Admin: http://localhost:3000/admin/login

The official studio logo can be uploaded later through the Studio Settings model and will replace the typography lockup in the header.
